## 🚀 Giới Thiệu
Trang Portfolio cá nhân phong cách **Minimalist & Editorial Design**, được tối ưu hóa cho trải nghiệm đọc nhanh, tiếp cận thông tin trực diện và trực quan trên cả máy tính lẫn thiết bị di động:
- **Section 01**: Kỹ năng kỹ thuật cốt lõi (Frontend, Backend & Clean Architecture, Database & Optimization).
- **Section 02**: Case Study dự án trọng tâm — *Automotive Retail CRM & Digital Solution Platform*.
- **Section 03**: Thông tin liên hệ & Curriculum Vitae (PDF Preview).

---

## 🛠️ Công Nghệ Sử Dụng
- **Design System:** Minimalist Editorial Style (Newsreader Serif + Inter Sans + JetBrains Mono).
- **Styling:** Tailwind CSS + Vanilla CSS tokens.
- **Interactions:** ScrollSpy, Active Section Tracking, Dark/Light Mode Switcher, Reading Progress Bar.

---

## 💻 Cách Khởi Chạy Cục Bộ (Local Development)
Trang web được xây dựng thuần tĩnh và siêu nhẹ. Bạn có thể mở trực tiếp `index.html` hoặc chạy máy chủ HTTP:

```bash
# Sử dụng Python
python -m http.server 3000

# Hoặc sử dụng Node.js npx serve
npx serve .
```
Truy cập: `http://localhost:3000`
